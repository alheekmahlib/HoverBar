## الحقائق التقنية الحرجة (التفاصيل في Docs/ARCHITECTURE.md)

1. macOS 27: كل عناصر الشريط (حتى طرف ثالث) تستضيفها عملية **ControlCenter**؛ `SystemUIServer` لا يملك شيئاً.
2. AX `kAXPosition` يعمل على `AXMenuBarItem` **الموسوم فقط** (عناصر آبل)، مرفوض على المستضافات.
3. الإخفاء الفعّال = **نافذة غطاء** (status item بعرض 10,000px عبر `ParkingAnchor`) تدفع العناصر خارج الشريط تلقائياً؛ السحب المُركّب (`CGEventItemDragger`، وصفة Ice) للتصحيح والاستعادة.
4. الصلاحيات (Accessibility + Screen Recording) ممنوحة لنسخة `/Applications` الموقعة بـ **Developer ID** — لا تُطلب مجدداً إلا إذا تغيّر التوقيع.
5. التشغيل الصحيح محلياً: `scripts/dev-run.sh` (بناء → توقيع → نسخ إلى /Applications → `open`). التشغيل المباشر للثنائي يكسر سياق الصلاحيات.

## أوامر سريعة

```bash
tail -f ~/Library/Logs/HoverBar.log          # مراقبة سلوك التطبيق حياً
scripts/dev-run.sh                           # دورة بناء+تشغيل كاملة
killall ControlCenter                        # إنقاذ: إعادة كل الأيقونات فوراً
HOVERBAR_RESTORE_ALL=1 … (open -a HoverBar --env …)   # وضع إنقاذ بديل
```

## فخاخ معروفة (لا تكررها)

- بناء ad-hoc (بلا `sign-dev.sh`) = ضياع الصلاحيات في كل rebuild.
- `sed` على ملفات Swift بمعاملات macOS (استخدم python للتعديلات المتعددة).
- فحص AX/السحب من طرفية الوكيل مستحيل (TCC) — كل التجارب داخل التطبيق نفسه ثم قراءة `~/Library/Logs/HoverBar.log`.
- SwiftLint مثبت محلياً الآن — شغّله قبل كل push.
